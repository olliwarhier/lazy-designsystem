Buttons lösen eine Aktion aus, z. B. Speichern, Absenden oder Öffnen eines Dialogs. Für Navigation zu einer anderen Seite wird ein [Link](#do--dont) verwendet.

<Demo>
  <Button variant="filled">Speichern</Button>
  <Button variant="outlined">Abbrechen</Button>
  <Button variant="text">Mehr erfahren</Button>
</Demo>

## Spezifikation

Dieser Abschnitt gilt für **alle** Frameworks. Figma: Komponente `Button`.

### Anatomie

1. **Container** – Fläche bzw. Kontur, Radius aus dem [Shape-Regler](../../tokens/shape/) (Rolle *Control*)
2. **Label** – kurzes Verb, `Body`-Schrift im Bold-Schnitt
3. **Icons** (optional) – vor und/oder nach dem Label

### Varianten

| Figma `Type` | Code `variant` | Verwendung |
| --- | --- | --- |
| Filled | `filled` | Die wichtigste Aktion einer Ansicht. Höchstens eine pro Bereich. |
| Outlined | `outlined` | Alternative Aktionen neben der wichtigsten. |
| Text | `text` | Untergeordnete Aktionen mit wenig visuellem Gewicht. |

### Größen

Figma: Collection `Components`, Modi Small / Medium / Large.

<Demo>
  <Button size="small">Small</Button>
  <Button size="medium">Medium</Button>
  <Button size="large">Large</Button>
</Demo>

### Zustände

| Figma `State` | Verhalten |
| --- | --- |
| Enabled | Grundzustand |
| Hovered | Overlay `--color-hovered-*` über der Fläche |
| Pressed | Overlay `--color-pressed-*` über der Fläche |
| Focused | Ring in `--color-focused-default-base`, nur bei Tastaturfokus |
| Disabled | Deckkraft `--color-disabled-opacity`, keine Interaktion |

**Interaction** (Figma: `Darker` / `Lighter`) legt fest, ob das Overlay abdunkelt oder aufhellt. `Lighter` ist für dunkle Flächen gedacht.

### Do & Don't

- **Do:** Labels als Verb formulieren („Speichern“, nicht „OK“).
- **Do:** Pro Bereich nur einen `filled`-Button.
- **Don't:** Buttons für Navigation verwenden – dafür gibt es Links.

### Accessibility

- Natives `<button>`-Element mit `type="button"` als Standard.
- Bedienbar mit <kbd>Enter</kbd> und <kbd>Leertaste</kbd>.
- Kontrast Label zu Fläche über die geprüften On-Farben (`--color-on-action-*`).
- Reine Icon-Buttons brauchen ein `aria-label` – dafür gibt es den Icon-Button.

### Tokens

| Component-Token | Small | Medium | Large |
| --- | --- | --- | --- |
| `--button-gap` | `--spacing-static-3xsmall` | `--spacing-dynamic-2xsmall` | `--spacing-dynamic-xsmall` |
| `--button-padding-y` | `--spacing-static-2xsmall` | `--spacing-dynamic-xsmall` | `--spacing-dynamic-small` |
| `--button-padding-x` | `--spacing-dynamic-xsmall` | `--spacing-dynamic-small` | `--spacing-dynamic-medium` |
| `--button-icon-size` | `--sizing-icon-small` | `--sizing-icon-medium` | `--sizing-icon-large` |
| `--button-font-size` | `--typescale-body-small-size` | `--typescale-body-medium-size` | `--typescale-body-large-size` |
| `--button-content-min-height` | `--sizing-icon-small` | `--sizing-icon-medium` | `--sizing-icon-large` |

Farben: `--color-action-default-base`, `--color-on-action-default-base`, `--color-on-surface-default-base`, `--color-on-surface-default-action`, `--color-outline-default-base`, `--color-hovered-*`, `--color-pressed-*`, `--color-focused-default-base`.

## Implementierung

<Tabs syncKey="framework">
  <TabItem label="Svelte">

```svelte
<script>
  import { Button, SizeProvider } from '@lazy-designsystem/svelte';
</script>

<Button onclick={save}>Speichern</Button>

<SizeProvider size="small">
  <Button variant="outlined">Filter</Button>
  <Button variant="text">Zurücksetzen</Button>
</SizeProvider>
```

| Prop | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `variant` | `'filled' \| 'outlined' \| 'text'` | `'filled'` | Figma: Type |
| `size` | `'small' \| 'medium' \| 'large'` | aus `SizeProvider`, sonst `'medium'` | Figma: Components-Modus |
| `interaction` | `'darker' \| 'lighter'` | `'darker'` | Figma: Interaction |
| `disabled` | `boolean` | `false` | |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Natives `type`-Attribut |
| `leading`, `trailing` | `Snippet` | – | Icons vor bzw. nach dem Label |
| `children` | `Snippet` | – | Label |

Weitere Attribute (z. B. `onclick`, `aria-label`) werden an das `<button>`-Element durchgereicht.
