Quelle der Wahrheit sind die **Figma Variables**. Änderungen an Tokens passieren in Figma und werden von dort ins Repo exportiert.

<Steps>

1. Variables in Figma exportieren, im W3C-DTCG-Format (`$value`, `$type`) – z. B. mit Tokens Studio oder einem Variables-Export-Plugin.

2. Die JSON-Dateien in `packages/tokens/src/` ersetzen.

3. Tokens bauen und Ergebnis prüfen:

   ```bash
   pnpm tokens
   pnpm dev
   ```

4. Changeset anlegen und Pull Request öffnen:

   ```bash
   pnpm changeset
   ```

</Steps>

<Aside>
  Die Figma-REST-API für Variables steht nur im Enterprise-Plan zur Verfügung. Ohne Enterprise läuft der Export über ein Plugin.
</Aside>
