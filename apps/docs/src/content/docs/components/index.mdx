Jede Komponente wird zuerst in Figma gestaltet und dann pro Framework umgesetzt. Die Svelte-Komponenten bauen auf [bits-ui](https://bits-ui.com/) auf – das liefert Verhalten und Barrierefreiheit, Lazy liefert das Aussehen über Tokens.

## Stand

| Komponente | Figma | Svelte | Größen-Tokens |
| --- | --- | --- | --- |
| [Button](button/) | ✓ | ✓ | `--button-*` |
| FAB | ✓ | geplant | `--fab-*` |
| Link | ✓ | geplant | `--link-*` |
| Chip | ✓ | geplant | `--chip-*` |
| Badge | ✓ | geplant | `--badge-*` |
| Tabs | ✓ | geplant | `--tab-*` |
| Text Field | ✓ | geplant | `--text-field-*` |
| Menu | ✓ | geplant | `--menu-item-*`, `--menu-label-*` |
| Date Picker | ✓ | geplant | `--date-picker-*` |
| Divider | ✓ | geplant | `--divider-*` |
| Icon | ✓ | geplant | `--icon-stroke-width` |
| Card | in Arbeit | – | – |

✓ = fertig · geplant = Spezifikation in Figma vorhanden, Code folgt

## Aufbau jeder Komponentenseite

- **Übersicht** – wofür, Varianten, Do & Don't
- **Gestaltung** – Anatomie, Größen, Zustände, Tokens
- **Code** – Props, Beispiele, Barrierefreiheit

Neue Komponenten entstehen nach der [Vorlage für neue Komponenten](../reference/contributing/).
