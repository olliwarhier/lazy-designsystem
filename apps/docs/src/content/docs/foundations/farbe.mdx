Farben gibt es auf zwei Ebenen. **Primitives** sind die Rohpalette, **semantische Tokens** geben einer Farbe eine Rolle. Komponenten verwenden ausschließlich semantische Tokens – so lässt sich z. B. ein Dark Mode umsetzen, ohne Komponenten anzufassen.
