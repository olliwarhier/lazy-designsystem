Jedes klickbare Element zeigt, in welchem Zustand es ist. Lazy legt dafür **keine eigene Farbe pro Zustand** an, sondern verändert die vorhandene Fläche nach einer Regel.

## Die Zustände

| Zustand | wann | sichtbar durch |
| --- | --- | --- |
| **Enabled** | Ruhezustand | Rollenfarbe der Komponente |
| **Hovered** | Mauszeiger darüber | Fläche etwas heller oder dunkler |
| **Pressed** | wird gerade geklickt oder getippt | Fläche deutlich heller oder dunkler |
| **Focused** | per Tastatur angewählt | Fokusring in `Focused` |
| **Disabled** | nicht verfügbar | ganze Komponente mit 48 % Deckkraft |

## Hovered und Pressed: Helligkeit verschieben

Bei Komponenten **mit Fläche** (z. B. Filled Button) wird die Helligkeit (OKLCH-Lightness) der Fläche verschoben:

- **Helle Flächen** (L ≥ 0,5) werden **dunkler**: Hovered −0,08, Pressed −0,16.
- **Dunkle Flächen** (L < 0,5) werden **heller**: Hovered +0,12, Pressed +0,24.

Ins Helle wird stärker verschoben, weil dunkle Töne kleine Unterschiede schlecht zeigen – ab etwa L 0,3 sieht man kaum noch, ob eine Fläche dunkler wird, und bei L 0,15 würde Pressed rechnerisch ins Negative fallen.

```css
.button:hover {
  background: oklch(from var(--button-bg) var(--interaction-hovered-l) c h);
}
```

Die Richtung lässt sich für einen Bereich festlegen, z. B. wenn eine Marke immer dunkler werden soll: `data-interaction="darker"` oder `"lighter"`.

## Focused

Der Fokusring ist immer sichtbar, sobald per Tastatur navigiert wird (`:focus-visible`):

```css
:focus-visible {
  outline: var(--base-border-width-focus) solid var(--color-focused-default-base);
  outline-offset: var(--base-border-width-focus);
}
```

Der Abstand trennt den Ring von der Komponente, damit er auch auf Flächen mit ähnlicher Farbe erkennbar bleibt. Auf invertierten Flächen wird `--color-focused-inverted-base` verwendet.

## Disabled

Deaktivierte Komponenten werden mit `--color-disabled-opacity` (0,48) abgeschwächt und reagieren nicht auf Hover. Eine Deckkraft statt eigener Disabled-Farben funktioniert auf jedem Untergrund und mit jeder Rollenfarbe – eigene Farben waren nicht auf allen Flächen erkennbar. Text auf deaktivierten Komponenten muss den Kontrast nicht erfüllen – die Funktion darf aber nie **nur** über den Disabled-Zustand erklärt werden.

<Aside type="tip">
  Lieber erklären, warum etwas nicht geht, als es nur auszugrauen – z. B. mit einem Hinweistext unter dem Formular.
</Aside>
