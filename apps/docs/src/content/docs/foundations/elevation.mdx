Elevation zeigt, was **über** etwas anderem liegt: ein Menü über der Seite, ein Dialog über allem. Lazy setzt Tiefe sparsam ein – die meisten Flächen liegen flach und werden über Farbe (`Surface`) unterschieden.

| Ebene | Effect Style in Figma | Einsatz |
| --- | --- | --- |
| Flach | – | Seiten, Bereiche; Unterscheidung über `Surface`-Stufen |
| Card | `Shadow/Card` | Karten, die sich leicht abheben |
| Floating | `Shadow/Floating` | alles, was über der Seite schwebt |
| Scrim | – | Abdunkelung hinter Dialogen und Sheets |

## Effect Styles

Die Effect Styles in Figma kombinieren zwei Schatten – einen weichen für die Tiefe und einen kurzen für die Kante:

```css
/* Shadow/Card */
box-shadow:
  0 0 24px var(--color-shadow-default-subtle),
  0 4px 8px var(--color-shadow-default-subtle);

/* Shadow/Floating */
box-shadow:
  0 8px 24px var(--color-shadow-default-base),
  0 4px 8px var(--color-shadow-default-bold);
```

<Aside type="caution" title="Noch nicht im Export">
  Effect Styles sind keine Variablen und werden deshalb noch nicht exportiert. Bis dahin stehen die Werte nur hier; geplant sind Tokens wie `--elevation-card` und `--elevation-floating` (siehe [Bekannte Probleme](../../reference/known-issues/)).
</Aside>
