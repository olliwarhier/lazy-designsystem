Farben gibt es auf zwei Ebenen. **Paletten** (Primitives) beschreiben Farbtöne, benannt nach ihrer Helligkeit. **Farbrollen** (System) geben einer Farbe eine Funktion – Komponenten verwenden ausschließlich Farbrollen.

Jede Fläche hat eine passende **On-Farbe** für Schrift und Icons darauf, deren Kontrast geprüft ist. Die Werte unten stammen direkt aus dem DS Template; die Spalten zeigen Light- und Dark-Mode. Wie die Namen entstehen, steht unter [Benennung](../../reference/naming/).

## Corporate

**Brand** für Flächen und Akzente der Marke, **Action** für klickbare Elemente, **Signal** für Hervorhebungen (verweist im Template auf Action).
