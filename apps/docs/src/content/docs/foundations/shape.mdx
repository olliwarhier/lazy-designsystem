Shape bestimmt, wie rund das Interface wirkt – von kantig bis vollständig abgerundet. Statt fester Stufen gibt es **einen Regler** `--shape` mit Werten von `0` (Square) bis `1` (Pill). Alle Radien werden daraus berechnet.

<ShapeDemo client:visible />

## Warum ein Regler statt fester Radien?

Ein voller Radius (Pill) funktioniert nur bei **einzeiligen Elementen** wie Buttons oder Chips. Auf großen Flächen (Modal, Card, Menu) oder mehrzeiligen Feldern (Text-Area) wirkt er falsch, und kleine Marker wie die Checkbox werden zum Kreis und sind nicht mehr von einem Radio-Button zu unterscheiden. Deshalb wirkt derselbe Regler auf drei Rollen unterschiedlich.

## Die drei Rollen

| Rolle | Komponenten | Formel | bei `--shape: 1` |
| --- | --- | --- | --- |
| **Control** | Button, Icon-Button, FAB, Chip, Text-Field, Tab, Badge, Switch | `--shape` × Höhe ÷ 2 | echte Pill |
| **Container** | Card, Menu, Modal, Sheet, Tooltip, Text-Area, Date-Picker | `--shape` × 24 px | 24 px |
| **Marker** | Checkbox | `--shape` × 8 px | 8 px |

Im CSS:

```css
:root {
  --shape: 0.5;
  --shape-container-max: var(--base-scale-300); /* 24 px */
  --shape-mark-max: var(--base-scale-100);      /*  8 px */

  --shape-radius-container: calc(var(--shape) * var(--shape-container-max));
  --shape-radius-mark: calc(var(--shape) * var(--shape-mark-max));
}

/* Controls kennen ihre Höhe und rechnen selbst */
.button {
  border-radius: calc(var(--shape) * var(--button-height) / 2);
}
```

Der Startwert von `--shape` entspricht dem Standard-Modus der Figma-Collection `Shapes` (im DS Template *Square* = `0`). Für eine Seite oder einen Bereich lässt er sich über ein Attribut setzen:

```html
<body data-shape="pill">
```

## Verschachtelte Radien

Liegt ein gerundetes Element in einem anderen, wird der innere Radius aus dem äußeren abgeleitet, damit die Abstände gleichmäßig wirken:

```css
.card-inner {
  border-radius: max(0px, calc(var(--shape-radius-container) - var(--card-padding)));
}
```

Der Fokus-Ring folgt derselben Regel in die andere Richtung: Radius des Elements **plus** Abstand des Rings.

## Bezug zu Figma

Figma-Variablen können nicht rechnen, deshalb bleiben in der Collection `Shapes` fünf Modi. Sie sind **Messpunkte desselben Reglers**:

| Figma-Modus | `--shape` |
| --- | --- |
| Square | `0` |
| Rounded-Subtle | `0.25` |
| Rounded-Medium | `0.5` |
| Rounded-Bold | `0.75` |
| Pill | `1` |

<Aside type="caution" title="Abgleich mit dem DS Template">
  Die heutigen Werte im DS Template weichen leicht von der linearen Formel ab (z. B. Modal: 0 / 8 / 12 / 16 / 24 px statt 0 / 6 / 12 / 18 / 24 px). Für eine exakte Übereinstimmung zwischen Figma und Code sollten die Figma-Werte an die Formeln angepasst werden. `Border-Radius/Focus` entfällt als eigener Wert, weil er sich aus dem Element-Radius ergibt.
</Aside>

Die Zuordnung der Figma-Variablen:

| Figma (`Shapes`) | Rolle im Code |
| --- | --- |
| `Border-Radius/General` | Control |
| `Border-Radius/Components/Checkbox` | Marker |
| `Border-Radius/Components/Tooltip`, `…/Modal`, `…/Sheet`, `…/Menu` | Container |
| `Border-Radius/Focus` | abgeleitet: Element-Radius + Abstand |
