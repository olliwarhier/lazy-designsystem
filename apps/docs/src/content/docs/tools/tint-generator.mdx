Alle Paletten teilen sich dieselben Stufen. Neutral- und Color-Paletten stehen in eigenen Kategorien, jede Kategorie hat ihr gemeinsames Chroma. Eine Zeile anklicken öffnet die Einstellungen der Palette. Die Paletten stehen danach im [Theme-Builder](../theme-builder/) zur Verfügung.

## So wird gerechnet

**Stufen-Basis „Kontrast" (Standard)**

- Gemessen wird gegen zwei Kontrast-Hintergründe (Standard `oklch(0.98 0 0)` und `oklch(0.2 0 0)`): helle Stufen gegen den dunklen, dunkle gegen den hellen.
- **Zentrum:** gleicher Kontrast zu beiden Hintergründen (APCA L 70, Lc 48). Es ist nur für Outlines da.
- **Pflichtstufen:** APCA Large 60 · Body 75 · Caption 90 · Maximum 100 (bei 7 Stufen Large und Caption). WCAG Body 7 · Caption 10 · Maximum 15 (bei 7 Stufen Body und Maximum). Dazu die Außenpunkte.
- **Weitere Stufen** halbieren die größte Kontrastlücke (APCA linear, WCAG logarithmisch).
- Der Stufenname ist das L der Neutral-Stufe. Bunte Paletten suchen das L, bei dem sie denselben Kontrast erreichen. Deshalb weicht ihr echtes L um einige Punkte ab.

**Stufen-Basis „Lightness" (Erweitert)**

- Zentrum fest: APCA L 70, WCAG L 57.
- Die Abstände bilden eine geometrische Reihe a, a·r, a·r², … vom Zentrum zum Außenpunkt. Liegt der erste Abstand unter 10, wird er auf 10 gesetzt (notfalls 8).
- Regler „Verteilung": 1 nutzt den kleinsten Faktor r, bei dem der letzte Abstand noch den Mindestabstand schafft, aber nie unter 0,5. Die dunkle Seite bekommt den halben Schub.

**Für beide**

- **Mindestabstand:** 3 L, wenn der obere Außenpunkt 100 ist, sonst 2 L.
- **Chroma:** C = Min + (Max − Min) × (1 − d²), d über die Stufe gemessen. Das Minimum wirkt hell voll, dunkel halb. „Konstant" nutzt überall das Maximum. Danach Gamut-Mapping nach CSS Color 4.
- **Neue Palette:** Hue der vorherigen Zeile + 45°, Name aus dem Hue.
