Lazy besteht im Code aus zwei Schichten:

1. **Tokens** (`@lazy-designsystem/tokens`) – CSS-Variablen, die jedes Framework nutzt.
2. **Komponenten** – eine Bibliothek pro Framework, die dieselben Spezifikationen umsetzt. Den Anfang macht Svelte.

Die Tokens eines Projekts kommen aus dessen Figma-Datei (siehe [Übergabe an Code](../../setup/handover/)); die Struktur und die Namen sind immer gleich.

## Installieren

Wähle dein Framework – die Auswahl gilt für alle Seiten der Doku.

1. Pakete installieren:

   ```bash
   pnpm add @lazy-designsystem/tokens @lazy-designsystem/svelte
   ```

2. Tokens einmal global laden, z. B. im Root-Layout:

   ```svelte
   <script>
     import '@lazy-designsystem/tokens/tokens.css';
   </script>
   ```

3. Komponenten verwenden:

   ```svelte
   <script>
     import { Button } from '@lazy-designsystem/svelte';
   </script>

   <Button>Speichern</Button>
   ```

  padding: var(--spacing-dynamic-xsmall) var(--spacing-dynamic-small);
}

## Modi umschalten

Alle Modi lassen sich über Attribute setzen – auf `<html>` für die ganze Seite oder auf einem Element für einen Bereich:

```html
<html data-color-scheme="dark" data-theme="wireframe" data-shape="pill">
```

| Attribut | Werte | ohne Attribut |
| --- | --- | --- |
| `data-color-scheme` | `light`, `dark` | folgt der Systemeinstellung |
| `data-theme` | Name eines Themes, z. B. `wireframe` | Standard-Theme |
| `data-shape` | `square` … `pill` | Standard aus Figma |
| `data-contrast` | `more`, `standard` (sobald es Kontrast-Modi gibt) | folgt der Systemeinstellung |

Größen von Komponenten werden per Prop gesetzt oder an einen Bereich vererbt (siehe [Größe & Dichte](../../foundations/size/)).

## Grundregeln

- Nur **System-Tokens** verwenden (`--color-*`, `--spacing-*`, `--typescale-*` …), nie Paletten oder die Base-Scale direkt.
- Keine festen Werte für Farben, Abstände, Schriftgrößen oder Radien.
- Für Rundungen den [Shape-Regler](../../foundations/shape/) nutzen, nicht feste Radien.
