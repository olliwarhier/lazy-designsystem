Versionen der Pakete werden mit [Changesets](https://github.com/changesets/changesets) gepflegt; die Einträge je Paket stehen in den `CHANGELOG.md`-Dateien im Repository.

## Oktober 2026

- **Neue Struktur der Doku:** Einführung, Grundlagen, Komponenten, Projekt aufsetzen, Referenz. Alte Adressen leiten weiter.
- **Neue Seiten:** Interaktion, Elevation, Icons, Barrierefreiheit, Alle Tokens, Übergabe an Code.
- **Englisch vorbereitet:** Die Doku ist zweisprachig angelegt, englische Seiten folgen.
- **Plugins dokumentiert:** Logik von Tints, Theme Builder und Typescale mit Live-Rechnern.
- **Figma-Fehler behoben:** Action-Bold im Dark Mode, Error-Paletten (siehe [Bekannte Probleme](../known-issues/#behoben)).
- **Tokens:** Export aus dem DS Template, Build für CSS und JSON, Shape-Regler, Interaction-Regel.
- **Svelte:** erste Komponente Button.
